Environment the situations the agent must handle
No dataset step in Level 2. A reinforcement-learning agent is not trained on a prepared dataset: it learns by trying actions in the simulator and receiving rewards, so training is the data generation (millions of simulated steps). This step lets you look at the simulated situations first.

Each episode: the arm must move from a start to a goal configuration (the goal comes from Level 1 IK) while obstacles block the path, a new obstacle appears mid-motion, obstacles drift, a joint slips, and the motors have a gain / bias error.

Solid robot = potential field (classical obstacle avoidance), orange = straight path (no avoidance). The potential field often gets stuck – that is what the DRL agent learns to fix.

Train the re-routing agent PPO · GPU updates, CPU simulation · live 3D view

The agent learns a small correction on top of the straight path to the goal, so it steers around obstacles that appear while it moves and recovers from joint slips and actuator errors.

How this works
PPO (proximal policy optimisation) with a 2 × 64 MLP. 64 PyBullet simulations run in CPU worker processes; the network's training updates run on the GPU. The command sent to the arm is straight-line controller + policy correction (residual RL), so an untrained agent behaves like the baseline and training only has to learn when and how to deviate.
